# 知识治理方法论

源自 Wcof 的 myknowledge-skill 项目，是 [[../ai-education/system/wiki-harness.md|ai-education 知识库治理体系]]的蓝图。

## 四条底层原则
1. **优先解决「以后怎么找」**——分类从检索需求长出来
2. **停止重复推导，开始持续编译**——增量编译而非 RAG 式即用即走
3. **建立知识生命周期**——draft → current → archive → unknown
4. **规则才是真正的产品**——wiki-harness.md 是宪法

## 理论支撑：SECI 模型（隐性知识 ↔ 显性知识）

> 来源：AI4KIDs《云笔记赋能教师个人知识管理》（2025-05-31，源自杭州市 2019 年教师现代教育技术小课题 19X17004）。
> ⚠️ 只取该文的**理论内核**，其工具层（云笔记）部分已过时，不入库。

日本学者**野中郁次郎**提出的 SECI 模型是知识管理领域的经典理论，揭示知识创造的核心在于**隐性知识与显性知识的相互转化**：

| 类型 | 定义 | 比喻 |
|------|------|------|
| **隐性知识** | 高度个人化、难以言传——教学直觉、经验、技巧、师生互动默契 | 冰山水下部分 |
| **显性知识** | 可编码、易传播——教案、论文、报告、标准化流程 | 冰山可见部分 |

**四种转化过程：**

| 过程 | 转化方向 | 场景 |
|------|---------|------|
| **社会化** Socialization | 隐性 → 隐性 | 师徒观察模仿 |
| **外在化** Externalization | 隐性 → **显性** | 把经验、感悟转化为文字、图表 |
| **组合化** Combination | 显性 → 显性 | 整合、系统化不同来源的显性知识 |
| **内在化** Internalization | 显性 → 隐性 | 学习、实践后内化为个人能力 |

**与本方法论的关系：**

本库的"**持续编译**"原则，本质是用工程手段**最大化「外在化」与「组合化」**——

> 碎片盒捕获隐性经验（外在化的起点）→ wiki 概念页做结构化组合 → Agent 萃取完成从原始素材到可复用知识的转化。

这也解释了为什么"**停止重复推导，开始持续编译**"是对的：每次重新推导 = 隐性知识始终停留在隐性状态；
而编译成文 = 完成外在化，此后可被反复组合复用。

## 实践工具：「思维支架」五问

用于引导深度反思、克服独立反思的疏离感。可在笔记模板或输入法快捷短语中预设：

1. 此信息的核心观点 / 对我的启示是什么？（**提炼**）
2. 与我已有的哪些知识 / 经验相关联？（**联结**）
3. 我认同 / 质疑其中的哪些部分？为什么？（**批判**）
4. 如何将其应用于我的教学 / 工作实践？（**迁移**）
5. 引发了我怎样的情绪或思考？（**元认知**）
