# 教师AI备课的正确“打开方式”：不是生成教案，而是拆解课堂

来源公众号：AI在教育

我们在用AI备课最容易踩的坑，是一上来就让AI生成教案。
真正更专业的用法，是把AI当成“备课参谋”，也就是说——
不要先生成教案，而要先拆解课堂。
一、AI直接写出来的教案，常常“像样但不好用”？因为AI很擅长生成一个“标准格式”。
但真实课堂不是格式。
真实课堂里，老师真正要面对的是：
学生原来会什么？
学生可能卡在哪里？
这个知识点到底难在哪里？
.....
这些才是备课的关键。
如果这些问题没想清楚，直接让AI生成教案，它就很容易给你一份“看起来完整”的文本。
但完整不等于好用。
所以，AI备课的第一步，不是写教案。而是把这节课拆开，先把课堂的关键问题想清楚。
二、AI备课的正确顺序：先拆课堂，再生成教案第一步：先让AI帮你做“学生困难预判”一节课真正难不难，不是看教材写得难不难，而是看学生会在哪里卡住。
所以专业的备课，应该先问：
学生学到这里，可能会误解什么？
这一步非常适合让AI参与。
可直接使用的提示词我是一名【学段】【学科】老师，正在准备【教学内容】。学生是【年级】，他们已有基础大致是【简单描述】。

请先不要写完整教案，而是帮我分析：
1. 学生学习这个内容时，最可能出现哪些理解困难？
2. 哪些地方容易产生表面会、实际不懂的情况？
3. 学生可能会有哪些错误回答或典型误解？
4. 老师可以通过哪些问题提前发现这些困难？
5. 针对每个困难，可以设计什么课堂支架？

要求：
分析要贴近真实课堂；
不要写空泛理论；
要具体到学生可能怎么想、怎么错。第二步：让AI帮你提炼“本节课最核心的问题”很多课不好上，不是因为老师不会讲，而是因为课堂没有一个清晰的核心问题。
一节课如果目标太散，活动太多，问题太碎，学生就容易跟着老师走流程，但不知道自己到底在解决什么。
所以，备课时要问：
这节课最想让学生想明白什么？
AI可以帮老师从教材内容里提炼核心问题。
可直接使用的提示词我正在准备一节关于【教学内容】的课。请帮我提炼这节课最核心的课堂问题。

要求：
1. 这个问题要能统领整节课；
2. 不能只是知识回忆题；
3. 要能推动学生思考；
4. 要适合【年级】学生；
5. 请给出3个备选核心问题，并说明每个问题适合怎样的课堂走向。

请用表格输出：
核心问题｜适合的课堂重点｜可能引发的学生思考｜使用建议
核心问题确定后，教案就不会散。
第三步：让AI帮你设计“问题链”，而不是只生成几个问题很多AI生成的课堂问题，看起来很多，但层次不清。
真正好的问题链，应该让学生一步步往深处走：
从看见现象，
到理解内容，
到分析原因，
到迁移生活，
到表达观点。
可直接使用的提示词我是一名【学段】【学科】老师，本节课内容是【教学内容】，核心问题是【填写核心问题】。

请帮我设计一组由浅入深的问题链。

要求：
1. 问题要适合【年级】学生；
2. 按照“观察—理解—分析—迁移—表达”五个层次设计；
3. 每个问题后面请设计一个教师追问；
4. 请说明这个问题想训练学生什么能力；
5. 问题语言要像真实课堂上老师会问的话。

请用表格输出：
层次｜课堂问题｜教师追问｜学生可能回答｜能力目标第四步：让AI帮你判断“哪里该讲，哪里该让学生做”很多教案不好用，是因为讲、问、练、做之间的比例不对。
AI生成的教案常常会把活动设计得很丰富，但不一定知道这个活动为什么存在。
这一步，就是课堂结构设计。
可直接使用的提示词本节课内容是【教学内容】，核心目标是【填写目标】，学生可能的困难是【填写困难】。

请帮我分析这节课的课堂结构：
1. 哪些内容适合教师直接讲解？
2. 哪些内容适合学生先观察或尝试？
3. 哪些内容适合同桌交流或小组讨论？
4. 哪些内容需要通过练习检查理解？
5. 哪个环节最需要教师收束提升？

请输出一份“讲—问—做—练—收束”的课堂结构建议。
要求：不要追求活动多，要追求每个环节都服务学习目标。第五步：让AI帮你设计“课堂活动”，但必须先问三个问题课堂活动不是越多越好。一个活动能不能用，关键看三件事：
第一，学生具体做什么？
第二，做的过程中学什么？
第三，做完之后如何回到本节课目标？
如果这三个问题答不清楚，活动再热闹也可能是假热闹。
可直接使用的提示词我想围绕【教学内容】设计一个课堂活动，服务的学习目标是【填写目标】。

请帮我设计3个活动方案，但每个方案都必须回答：
1. 学生具体要做什么？
2. 学生在做的过程中会学到什么？
3. 活动结束后，教师如何收束回本节课目标？
4. 这个活动可能出现什么问题？
5. 如果学生参与不充分，教师可以怎样调整？

要求：
活动简单可操作；
不需要复杂材料；
不要只追求热闹；
必须服务学习目标。第六步：最后才让AI生成“教案初稿”前面五步做完以后，再让AI生成教案，质量就会明显提高。
这时生成出来的教案，才更接近真实课堂。
可直接使用的提示词请根据以下备课信息，帮我生成一份课堂教学初稿。

学段学科：
【填写】

教学内容：
【填写】

学生可能困难：
【填写】

本节课核心问题：
【填写】

问题链：
【填写】

课堂结构：
【填写】

课堂活动：
【填写】

请生成一份教案初稿，包含：
1. 教学目标；
2. 教学重点与难点；
3. 课堂导入；
4. 核心问题推进；
5. 学生活动；
6. 教师追问；
7. 课堂练习或检测；
8. 课堂小结；
9. 作业建议。

要求：
语言自然；
适合真实课堂；
不要写得过于宏大；
活动不要过多；
每个环节都要服务核心问题。三、一份AI教案能不能用，老师要看这5点以后AI生成教案后，不要先看它写得完整不完整，而要先看这5点。
1. 有没有学生？有没有写清学生可能不会什么、误解什么、卡在哪里。
2. 有没有核心问题？整节课是不是围绕一个关键问题推进。
3. 有没有问题链？问题是不是由浅入深。
4. 活动有没有回到目标？每个活动都要回答：学生做完之后，学到了什么？
5. 有没有检测学生是否真的理解？看学生能不能说出来、做出来、解释出来、迁移出来。
最后总结一句——教师+AI备课的真正顺序——拆学情 → 找困难 → 定核心问题 → 设计问题链 → 安排课堂结构 → 设计活动与检测 → 生成教案初稿 → 教师本土化修改。
