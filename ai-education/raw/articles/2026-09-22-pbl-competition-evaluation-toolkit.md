小学项目化融合课赛课评价工具包

电教教研员评赛专用 · 学科核心素养为主坐标 · 信息技术融合为增值维度

【使用假设与说明】
1. 适用对象：区（县）电教 / 学科教研员，用于小学（1–6 年级）「项目化学习 + 信息技术融合」赛课的评价与反馈。
2. 「融合课」界定：以信息技术与学科教学深度融合为特征的学科项目化学习课；若参赛课为跨学科主题学习，请同步使用第七部分《跨学科协同评价单》。
3. 本工具含两类：① 裁决类——《赛课评分量表》（100 分制，用于现场打分、排出名次）；② 研训类——课堂观察记录表、评价量规模板、过程性证据清单、评委反馈对话单、跨学科协同评价单（用于赛后反馈与教师研训，不计入名次）。
4. 权重为推荐值，可按区域实际微调；但须守住一条红线：学科核心素养是主坐标，技术融合维度权重不超过 25%。

第一部分　评赛理念与评委须知（优化后的角色定位）

1.1　总原则（三条）

- 学科为主坐标：评价第一问永远是「学生学科核心素养是否真实生长」，技术只是条件性、支持性、增值性维度。
- 从评教到评学：观察重心从教师讲授行为转向学生学习行为、思维过程、作品证据。
- 证据导向：以「目标—任务—证据—判断—反馈—改进」闭环，代替「听一节课、打一个分」的线性逻辑。

1.2　评委角色转变（对照原资料优化）

原资料强调「从评判者到证据导向的观察者与反馈设计者」。结合小学赛课实际，评委应同时承担三种角色：

- 观察者：捕捉学生真实学习证据，不评教师「表演」。
- 解读者：判断证据是否指向学科素养的真实生长。
- 反馈者：赛后以「证据先行」方式帮助教师改进（见第六部分）。

1.3　小学项目化融合课评赛红线（判断边界，新增）

以下情形触发即按对应处理，并在评语中注明。学科素养未发展，技术再热闹也判低效。

- 红线① 学科素养未发展：技术炫目但学生学科关键能力未提升 → 总分直接降一档。
- 红线②「为用而用」：技术无明确学科增值理由 → 技术维度不得分或扣分。
- 红线③「拼盘式」跨学科：多学科无内在逻辑拼接 → 跨学科维度判「拼盘」，不认定整合。
- 红线④ 教师代劳 / 表演：成果由教师包办或课堂像舞台表演 → 学科实践深度维度扣分。
- 红线⑤ 技术替代思考：用 AI / 工具替代本应由学生完成的思考 → 技术维度判「替代思考」，倒扣。

1.4　评分量表使用说明

- 评分采用 100 分制，5 个一级维度，下设评分要素。
- 每个要素按「优秀 / 良好 / 合格 / 待改进」四档描述，评委据课堂证据对应打分。
- 多评委时去掉一个最高分、一个最低分后取平均；单人评委可直接计分。
- 总分等级：≥90 特等奖候选 / 80–89 一等奖 / 70–79 二等奖 / 60–69 三等奖 / <60 不获奖。
- 出现红线情形时按 1.3 相应处理（降档或倒扣），并在评语中注明。

4.1　小学学科适配示例

- 语文（小学）：维度如「朗读与表达、阅读理解与建构、习作与创意表达、文化感受」；技术维度——是否用数字工具优化表达呈现、在数字化协作中提升语言交流质量。
- 数学（小学）：维度如「发现问题与建模、策略选择与运算、反思与优化」；技术维度——是否用数据 / 可视化工具外显数学思维。
- 科学（小学）：维度如「提出猜想与计划、观察与实验、证据与解释、态度责任」；技术维度——是否用传感器 / 模拟工具支持探究。
- 英语（小学）：维度如「听说交流、阅读理解、表达与展示」；技术维度——是否用配音 / 朗读 / 对话工具提升语言实践。

4.2　使用建议

- 每维度等级描述使用可观察的行为语言，避免「较好 / 一般」等模糊表述。
- 选 2–3 个最核心的维度重点评价，避免面面俱到导致师生负担过重。
- 量规课前公开，让学生理解标准并对照改进，而非项目结束后才见到。

5.1　证据链完整性检查（是 / 否）

- 是否覆盖项目全过程，而非只有最终成果？
- 证据是否能够支撑对学科核心素养的判断？
- 技术工具中的学习痕迹是否被有效采集和利用？
- 证据是否被用于后续反馈和教学调整？
- 学生是否有机会看到并解读自己的证据？

第六部分　评委反馈对话单（赛后 / 磨课）

核心理念：证据先行、判断在后 —— 不急于给结论，先请教师展示过程性证据，共同解读，再形成改进方向。

- 第一步　描述证据（10–15 分钟）：请教师展示过程性证据；哪些采集到 / 流失；最印象深刻的学科表现及证据。
- 第二步　解释意义（10–15 分钟）：证据能否支撑素养判断？素养证据在哪？目标—任务—评价是否一致？技术促进还是遮蔽学习？
- 第三步　聚焦问题（10 分钟）：最想改什么？量规是否真被使用 / 前置？技术工具是否需调整、替换或删减？
- 第四步　提出改进（5–10 分钟）：改进方向 + 具体行动 + 预期时间。
- 第五步　跟踪再评：改进是否发生？学生素养是否得到更好发展？

评委自我提醒：帮助教师看见证据、解读证据、改进教学；角色是协作者与引导者，而非标准颁布者；对话始终以学科核心素养为主线。

第八部分　评委使用手册（操作指南）

赛前

- 研读本工具包与评分量表，统一尺度（建议赛前用 1–2 节录像试评校准）。
- 打印《赛课评分量表》与《课堂观察记录表》。

赛中

- 听课同时填写观察记录表，记录关键证据。
- 下课后 30 分钟内完成评分量表打分，写亮点与建议。
- 多人评委去掉最高、最低分取平均。

赛后

- 汇总计分，确定等级与名次。
- 用反馈对话单与参赛教师做 1 次证据先行反馈（可线上）。
- 收集优秀量规 / 证据案例，建立区域评价案例库。

注意事项

① 守住红线，学科为主坐标；② 不评教师表演，评学生学习；③ 技术维度权重不超过 25%；④ 评语具体、有证据，避免「教态自然」等空话。
