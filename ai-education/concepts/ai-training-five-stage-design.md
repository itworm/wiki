# AI赋能教育培训设计——刘欣五段式提纲

## 五段式培训结构（可复用）

```
破冰（提问引发思考）
  → 现象审视（K型分化警示）
  → 谬误挖掘（小组活动：技术崇拜/效率陷阱/数据暴力）
  → 案例深剖（教师用AI备课的初心）
  → 第一性原理（Volition→独立思考→品味→进化）
```

## 关键设计亮点

1. **破冰用核心悖论**：工具让成事更容易，同时带来"认知卸载"
2. **现象层引数据/趋势**：K型分化——中间层消失
3. **谬误层用小组活动**：让学员自己选最大谬误剖析，参与式学习
4. **案例层讲初心**：偷懒初心 vs 正确初心
5. **升华层接第一性原理**：从工具使用升维到教育本质
