# 上海市中小学人工智能素养评价框架

> 2026年7月，上海发布中小学AI素养评价框架，从"有课可上"走到"有尺可量"。四维度+三水平的设计为区域AI教育评价提供了可复制的参照模板。

---

## 框架概览

### 四个核心维度

| 维度 | 内涵 |
|------|------|
| **人工智能意识** | 对AI技术存在、价值与局限的认知 |
| **人工智能思维** | 运用计算思维、系统思维理解和分析AI问题的能力 |
| **人工智能应用与创新** | 使用AI工具解决问题并进行创造性实践的能力 |
| **人工智能社会责任** | AI使用中的伦理判断、安全意识和责任担当 |

### 三个递进水平

```
感知理解 → 实践应用 → 协同创新
```

每学段在这三个水平上逐级递进，而非各学段独立设置不同标准。

## 学段差异化设计

| 学段 | 聚焦方向 | 典型任务示例 |
|------|---------|-------------|
| 小学 | 表达与元认知 | 使用AI前该思考哪些问题、如何提出好问题 |
| 初中 | 数据与模型 | AI之"智"从何而来、出错时如何判断问题在哪里 |
| 高中 | 伦理与人机协作 | AI的能力边界辨析、人机协作规范制定 |

## 核心设计理念

**以评促学、以评促教** — 体现人的主体性、价值观，塑造批判性思维与对AI本质的深层理解。

## 对区域电教站的价值

**1. 评价参照** — 这是国内第三个省级AI素养框架（继广东、杭州之后），上海版的四维度设计比广东版更聚焦评价实操，可直接作为区域制定本地化AI素养评价标准的模板。

**2. 实现路径清晰** — 框架配套单元评估任务示例和交互式综合评估任务，降低了从框架到落地的门槛。区域可以直接参考甚至复用这些评估任务。

**3. 进阶设计可迁移** — 小学→初中→高中逐级递进的水平设计，对区域设计K-12 AI素养培养路径有直接参考价值。

**4. "从有课可上到有尺可量"** — 这个转变本身就是区域推进AI教育的一个关键节点信号：先解决开课问题，再解决评价问题。
