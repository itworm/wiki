# AI-TPACK框架——从用好技术到让学习被看见

## 核心命题

教师专业知识的中心，从"如何用好技术"转向"如何让真正的学习被看见"。

## 框架结构

```
AI素养环境（最外围）
  ├── 内容C：鉴赏和批判知识
  ├── 教学法P：设计思维发生过程
  ├── 技术T：与AI对话协作
  └── AIPCK（中心）：目标显性化 / 思维可见化 / 证据闭环
轴心：决断知识（DK）——何时/为何/如何使用或拒绝AI
```

## 核心判断

> 技术越强，越需要回到最朴素的问题：学生的大脑在转动吗？你能证明吗？
