# 教研手记索引

> **这里存什么**：与本地老师讨论中产生的教研建议——**无成文、无 URL、一次讨论出多条**。
> **不是文章，是病例**：谁、卡在哪、我怎么建议的、后来怎么样。
> **硬规则**：同一主题满 **3 条** → 提炼成 `concepts/` 页面；单条永远留在这里，不删。

## 记一条的格式

```markdown
### YYYY-MM-DD 一句话标题
**场景**：（谁 / 什么需求 / 卡在哪）
**我的建议**：（原话，可直接引用）
**后来**：（可空，验证后再补）
```

## 什么不必记

某个建议**从不再出现**（一次性）→ 直接扔碎片盒，不进这里。
判据：**这个建议我是不是第三次说了？**
